# اعلان‌های خودکار و یادآوری بازی

یادآوری «یک ساعت پیش از بازی» و هر قانونی که مدیر در **پنل مدیریت ← اعلان‌ها ← اعلان‌های خودکار** می‌سازد، توسط زمان‌بندِ داخلیِ خود اپ هر دقیقه اجرا می‌شود (`src/instrumentation.ts`). روی ویندوز سرور یا لینوکس **هیچ تنظیمی لازم نیست** — نه Task Scheduler و نه cron.

شرط‌های قابل انتخاب:

| شرط | توضیح | تکرار |
|---|---|---|
| قبل از شروع بازی | X دقیقه/ساعت/روز پیش از هر رزرو | یک بار برای هر رزرو |
| بعد از پایان بازی | X دقیقه پس از پایان هر رزرو | یک بار برای هر رزرو |
| بازیکن غیرفعال | X روز بدون رزرو | حداکثر هر X روز یک بار، ۱۰ صبح تا ۹ شب |
| کیف پول کم | موجودی کمتر از مبلغ تعیین‌شده | حداکثر هفته‌ای یک بار، ۱۰ صبح تا ۹ شب |
| زمان مشخص | یک بار برای همه‌ی بازیکنان | یک بار |

در متن پیام می‌شود از `{name}` `{court}` `{time}` `{date}` `{balance}` `{days}` استفاده کرد.

جدول `notification_rule_deliveries` با کلید یکتا تضمین می‌کند هیچ‌کس یک پیام را برای یک رویداد دو بار نگیرد، حتی وقتی چند نسخه‌ی سرور هم‌زمان اجرا شوند.

## اجرای دستی یا با cron بیرونی (اختیاری — مثلاً روی Vercel)

```
GET /api/cron/reminders
Authorization: Bearer <CRON_SECRET>
```

بدون `CRON_SECRET`، توکن از `AUTH_SECRET` ساخته می‌شود و فقط خود سرور آن را می‌داند.

## اعلان روی گوشی (Web Push)

- بازیکن در صفحه‌ی «اعلان‌ها» دکمه‌ی «روشن کردن اعلان» را می‌زند (راهنمای اندروید و آیفون همان‌جاست). آیفون فقط وقتی اپ به صفحه‌ی اصلی اضافه شده باشد اعلان می‌گیرد (iOS 16.4+).
- کلیدهای VAPID خودکار ساخته و در جدول `app_settings` نگه داشته می‌شوند.
- اعلان از سرور شما به سرویس اعلانِ گوگل (اندروید) یا اپل (آیفون) فرستاده می‌شود. اگر سرور در ایران به این سرویس‌ها دسترسی ندارد، در `.env` مقدار `PUSH_PROXY` را بدهید. برای آزمایش، بعد از روشن کردن اعلان دکمه‌ی «ارسال اعلان آزمایشی» را بزنید؛ اگر نرسید، پیغام خطا همین را می‌گوید.
- پیام‌ها همیشه در صندوق «اعلان‌ها»ی اپ هم ذخیره می‌شوند، پس حتی بدون اعلان گوشی چیزی گم نمی‌شود.
