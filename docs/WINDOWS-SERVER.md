# نصب پرشین پدل روی ویندوز سرور

راهنمای کامل استقرار روی سرور ویندوزی ایرانی با دامنه‌ی `persianpdl.ir`.

از صفر تا سایتِ بالا، حدود **۴۵ تا ۹۰ دقیقه** وقت می‌برد — بیشترش صبرکردن
برای نصب پیش‌نیازها و رسیدن دامنه است.

## ۱. چه چیزی بخرید

### سرور

این برنامه یک اپلیکیشن **Node.js** است، نه PHP. پس:

> ⚠️ **هاست اشتراکی ویندوز به درد نمی‌خورد.**
> هاست اشتراکی ویندوز معمولاً فقط ASP.NET و PHP اجرا می‌کند و به شما اجازه‌ی
> نصب Node.js و PostgreSQL و ساخت سرویس ویندوز نمی‌دهد. برای این پروژه به
> **VPS ویندوز** یا **سرور اختصاصی** نیاز دارید (دسترسی RDP با کاربر Administrator).

**حداقل مشخصات:**

| | حداقل | پیشنهادی |
|---|---|---|
| CPU | ۲ هسته | ۴ هسته |
| RAM | ۴ گیگابایت | ۸ گیگابایت |
| دیسک | ۴۰ گیگابایت SSD | ۸۰ گیگابایت SSD |
| ویندوز | Server 2019 | Server 2022 |

**چرا ۴ گیگ رم حداقل است:** خودِ ویندوز سرور حدود ۲ گیگ می‌گیرد، PostgreSQL
حدود ۵۰۰ مگ، و اپ زیر بار تا ۱ گیگ. با ۲ گیگ، سرور شروع می‌کند به swap کردن
و همه‌چیز کند می‌شود.

**هنگام خرید حتماً بپرسید:**
- دسترسی Administrator کامل با RDP دارم؟ (باید بله باشد)
- می‌توانم نرم‌افزار دلخواه نصب کنم؟ (باید بله باشد)
- پورت‌های ۸۰ و ۴۴۳ باز هستند؟
- IP اختصاصی دارم؟ (برای SSL لازم است)

### دامنه

`persianpdl.ir` را از هر ثبت‌کننده‌ی مجاز ایرانی بگیرید. دامنه‌ی `.ir` از
[ایرنیک](https://www.nic.ir) ثبت می‌شود.

## ۲. پیش‌نیازها روی سرور

با RDP به سرور وصل شوید و این سه مورد را نصب کنید. **ترتیبش مهم نیست**، ولی
هر سه باید پیش از اجرای نصب‌کننده انجام شده باشند.

### الف) Node.js

از [nodejs.org](https://nodejs.org/en/download) نسخه‌ی **LTS** را با
`Windows Installer (.msi)` بگیرید.

هنگام نصب:
- ✅ گزینه‌ی **Add to PATH** حتماً تیک بخورد
- ❌ گزینه‌ی «Tools for Native Modules» لازم نیست

بررسی در PowerShell:
```powershell
node --version    # باید v20 یا بالاتر باشد
```

### ب) PostgreSQL

از [postgresql.org](https://www.postgresql.org/download/windows/) نسخه‌ی
**۱۶** را بگیرید.

هنگام نصب:
- رمز کاربر `postgres` را **یادداشت کنید** — نصب‌کننده‌ی ما آن را می‌پرسد
- پورت را روی `5432` بگذارید
- Locale را روی `Default` بگذارید
- در پایان، «Stack Builder» را **رد کنید**

### ج) ماژول‌های IIS

این دو ماژول برای اینکه دامنه به اپ برسد لازم‌اند. هیچ‌کدام پیش‌فرضِ ویندوز نیستند:

1. [URL Rewrite 2.1](https://www.iis.net/downloads/microsoft/url-rewrite)
2. [Application Request Routing 3.0](https://www.iis.net/downloads/microsoft/application-request-routing)

> 💡 اگر سرور به سایت‌های خارجی دسترسی ندارد (روی هاست‌های ایرانی معمول است)،
> این فایل‌ها را روی کامپیوتر خودتان دانلود کنید و با RDP کپی کنید
> (کپی‌پیست معمولی در پنجره‌ی RDP کار می‌کند).

## ۳. تنظیم دامنه

در پنل مدیریت دامنه، دو رکورد **A** بسازید:

| نوع | نام | مقدار |
|---|---|---|
| A | `@` | IP سرور شما |
| A | `www` | IP سرور شما |

سپس صبر کنید تا پخش شود. معمولاً ۱۰ دقیقه تا ۲ ساعت، گاهی تا ۲۴ ساعت.

بررسی از داخل سرور:
```powershell
Resolve-DnsName persianpdl.ir -Type A
```
اگر IP سرور را برگرداند، آماده‌اید.

> ⚠️ **پیش از رسیدن دامنه سراغ SSL نروید.** Let's Encrypt برای صدور گواهی
> خودش از بیرون به دامنه سر می‌زند؛ اگر دامنه نرسیده باشد، شکست می‌خورد و
> تعداد تلاش‌های ناموفق محدود است.

## ۴. نصب برنامه

### گام ۱ — ساخت بسته (روی کامپیوتر خودتان)

```bash
git clone <آدرس مخزن>
cd Paddel
npm install
bash deploy/windows/build-package.sh
```

خروجی: `dist/persian-padel-windows.zip` (حدود ۹۰ مگابایت)

این بسته **کامل** است: خود برنامه، موتور پایگاه داده‌ی مخصوص ویندوز، ابزار
مهاجرت، و همه‌ی اسکریپت‌های نصب. روی سرور به `npm install` و اینترنت نیاز ندارد.

### گام ۲ — انتقال به سرور

فایل zip را با RDP در مسیر مثلاً `C:\Users\Administrator\Desktop` کپی و
**Extract** کنید.

### گام ۳ — اجرای نصب‌کننده

PowerShell را با **Run as Administrator** باز کنید:

```powershell
cd C:\Users\Administrator\Desktop\persian-padel-windows

# فقط بار اول، تا اجازه‌ی اجرای اسکریپت داده شود
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

.\Install.ps1 -Domain persianpdl.ir
```

نصب‌کننده این کارها را می‌کند:

1. پیش‌نیازها را بررسی می‌کند
2. رمز `postgres` را می‌پرسد
3. پایگاه داده و یک کاربر اختصاصی می‌سازد
4. برنامه را در `C:\PersianPadel` می‌گذارد
5. فایل `.env` را با کلیدهای تصادفی می‌سازد
6. جدول‌ها را می‌سازد و داده‌ی اولیه را وارد می‌کند
7. برنامه را به‌عنوان سرویس ویندوز ثبت می‌کند
8. IIS را تنظیم می‌کند
9. فایروال را تنظیم می‌کند

**در پایان، رمز پایگاه داده را نشان می‌دهد — یادداشتش کنید.**

> 💡 اسکریپت **بارها قابل اجراست**. اگر وسط کار قطع شد، دوباره اجرایش کنید؛
> هر مرحله‌ای که انجام شده رد می‌شود. فایل `.env` هرگز بازنویسی نمی‌شود.

### تحویل واقعی بدون داده‌ی نمونه

برای نصب روی محیط واقعی که نمی‌خواهید بازیکن و زمینِ آزمایشی داشته باشید:

```powershell
.\Install.ps1 -Domain persianpdl.ir -NoSeed
```

بعد خودتان از پنل مدیریت، زمین‌ها و قیمت‌ها را وارد کنید.

## ۵. گواهی SSL

بدون SSL، مرورگرها سایت را «ناامن» نشان می‌دهند و **درگاه پرداخت هم قبولش
نمی‌کند**. پس اختیاری نیست.

### گزینه‌ی الف — رایگان (Let's Encrypt)

```powershell
.\Setup-SSL.ps1 -Domain persianpdl.ir -Email you@example.com
```

گواهی می‌گیرد، به IIS وصل می‌کند، و **تمدید خودکار هر ۶۰ روز** را تنظیم می‌کند.

### گزینه‌ی ب — گواهی خریداری‌شده

اگر از شرکت ایرانی گواهی خریده‌اید و فایل `.pfx` دارید:

```powershell
.\Setup-SSL.ps1 -Domain persianpdl.ir -PfxPath C:\certs\persianpdl.pfx
```

### نکته‌ی مهم درباره‌ی ترتیب

هدایت اجباری `http → https` و هدر HSTS **عمداً** تا پیش از نصب گواهی خاموش‌اند.
اگر زودتر روشن شوند و https کار نکند، سایت در حلقه‌ی بی‌پایان می‌افتد و اصلاً
باز نمی‌شود. اسکریپت اول https را واقعاً آزمایش می‌کند و فقط بعد از موفقیت
روشنشان می‌کند.

## ۶. پیامک

بدون پیامک، **هیچ‌کس نمی‌تواند ثبت‌نام کند** — کد تأیید فقط در لاگ سرور چاپ می‌شود.

فایل `C:\PersianPadel\.env` را با Notepad باز کنید:

```ini
OTP_PROVIDER=kavenegar
KAVENEGAR_API_KEY="کلید-شما"
KAVENEGAR_TEMPLATE="verify"
```

سپس:
```powershell
Restart-Service PersianPadel
```

سرویس‌های پشتیبانی‌شده: `kavenegar`، `smsir`، `ghasedak`، `console` (فقط توسعه).

> برای کاوه‌نگار باید یک «الگو» (template) در پنلشان بسازید و نامش را اینجا
> بگذارید. متن الگو باید جای `%token` داشته باشد.

## ۷. درگاه پرداخت

راهنمای کامل و جداگانه: **[PAYMENT-GATEWAY.md](PAYMENT-GATEWAY.md)**

خلاصه‌اش: در `.env` مقدار `PAYMENT_PROVIDER` را از `mock` به `zarinpal` یا
`zibal` یا `nextpay` عوض کنید و کلید درگاه را بگذارید.

> 🔒 تا وقتی `PAYMENT_PROVIDER=mock` باشد، برنامه در حالت production
> **عمداً** خطا می‌دهد و اجازه‌ی پرداخت نمی‌دهد. این محافظ است، نه اشکال —
> درگاه آزمایشی هر پرداختی را «موفق» اعلام می‌کند و اگر روی سایت واقعی فعال
> بماند، هر کسی می‌تواند کیف پولش را رایگان شارژ کند.

## ۸. کارهای پس از نصب

### ✅ رمز مدیر را عوض کنید

اگر با داده‌ی نمونه نصب کرده‌اید، کاربر `admin` با رمز `Admin@12345` ساخته شده.
**همین الان** واردش شوید و از «پروفایل ← تغییر رمز» عوضش کنید.

### ✅ پشتیبان‌گیری خودکار

```powershell
cd C:\PersianPadel\deploy\windows
.\Backup-Database.ps1 -InstallSchedule -KeepDays 30
```

هر شب ساعت ۳ بامداد پشتیبان می‌گیرد.

> ⚠️ پشتیبانی که روی همان دیسکِ سرور است، با خرابیِ همان دیسک از بین می‌رود.
> هر چند وقت یک بار یک فایل از `C:\PersianPadel\backups` را جای دیگری هم نگه دارید.

### ✅ ساعت سرور

```powershell
Set-TimeZone -Id 'Iran Standard Time'
w32tm /resync
```

برنامه ساعت باشگاه را از `APP_TIMEZONE` می‌خواند و مستقل از ساعت ویندوز درست
کار می‌کند، ولی برای درستیِ لاگ‌ها و گواهی SSL بهتر است ساعت سرور هم درست باشد.

### ✅ به‌روزرسانی ویندوز

```powershell
Install-Module PSWindowsUpdate -Force
Get-WindowsUpdate -Install -AcceptAll
```

## ۹. نگهداری روزمره

### دستورهای پرکاربرد

```powershell
# وضعیت
Get-Service PersianPadel

# ری‌استارت (بعد از هر تغییر در .env)
Restart-Service PersianPadel

# دیدن لاگ زنده
Get-Content C:\PersianPadel\logs\app.log -Tail 50 -Wait

# دیدن خطاها
Get-Content C:\PersianPadel\logs\app-error.log -Tail 50

# پشتیبان دستی
C:\PersianPadel\deploy\windows\Backup-Database.ps1
```

### به‌روزرسانی به نسخه‌ی جدید

روی کامپیوتر خودتان بسته‌ی جدید بسازید، به سرور کپی و باز کنید، سپس:

```powershell
cd C:\PersianPadel\deploy\windows
.\Update-App.ps1 -NewPackage C:\Users\Administrator\Desktop\persian-padel-windows
```

این اسکریپت اول پشتیبان می‌گیرد، بعد سرویس را می‌خواباند، فایل‌ها را عوض
می‌کند (**`.env` را دست نمی‌زند**)، مهاجرت‌ها را اجرا می‌کند، و سرویس را
بالا می‌آورد. اگر چیزی خراب شود، نسخه‌ی قبلی در `C:\PersianPadel\rollback` است.

## ۱۰. رفع اشکال

### سایت باز نمی‌شود

به ترتیب بررسی کنید — از داخل به بیرون:

```powershell
# ۱. آیا خودِ اپ بالاست؟
Invoke-WebRequest http://127.0.0.1:3000/api/health
```
اگر این جواب نداد → مشکل از اپ است، `logs\app-error.log` را ببینید.

```powershell
# ۲. آیا سرویس اجرا می‌شود؟
Get-Service PersianPadel
```

```powershell
# ۳. آیا IIS درخواست را پاس می‌دهد؟
Invoke-WebRequest http://localhost -Headers @{Host='persianpdl.ir'}
```
اگر این جواب نداد ولی مورد ۱ جواب داد → مشکل از IIS است. معمولاً یعنی
ARR یا URL Rewrite نصب نیست.

```powershell
# ۴. آیا دامنه به اینجا می‌رسد؟
Resolve-DnsName persianpdl.ir
```

### خطای «Query engine not found»

یعنی موتور پایگاه داده‌ی مخصوص ویندوز در بسته نیست. بسته را دوباره با
`build-package.sh` بسازید — آن اسکریپت وجودش را بررسی می‌کند و اگر نباشد
شکست می‌خورد.

### سرویس بالا نمی‌آید

```powershell
Get-Content C:\PersianPadel\logs\app-error.log -Tail 40
```

شایع‌ترین دلیل‌ها:
- رمز پایگاه داده در `.env` غلط است
- سرویس PostgreSQL خاموش است → `Start-Service postgresql*`
- پورت ۳۰۰۰ را برنامه‌ی دیگری گرفته → `Get-NetTCPConnection -LocalPort 3000`

### همه چیز کند است یا هنگ می‌کند

```powershell
# آیا محدودیت اتصال پایگاه داده تنظیم شده؟
Select-String -Path C:\PersianPadel\.env -Pattern 'connection_limit'
```
باید `connection_limit=10` داشته باشد. بدون آن، زیر بار اتصال‌ها ته می‌کشند.

```powershell
# آیا استخر نخ‌ها تنظیم است؟
Get-Content C:\PersianPadel\.env | Select-String 'UV_THREADPOOL_SIZE'
```
باید `8` باشد. این روی سرعت ورودهای هم‌زمان اثر مستقیم دارد.

### گواهی SSL تمدید نشد

```powershell
Get-ScheduledTask -TaskName 'win-acme*' | Get-ScheduledTaskInfo
```
اگر `LastTaskResult` صفر نیست، دستی اجرا کنید:
```powershell
C:\PersianPadel\tools\win-acme\wacs.exe --renew --force
```
