# کاتالوگ سه‌لت — اپ هوشمند زمین پدل

| فایل | کاربرد |
|---|---|
| `smart-padel-court-trifold.pdf` | نسخه‌ی نمایش و ارسال (A4 افقی، ۲۹۷×۲۱۰ میلی‌متر، ۲ صفحه) |
| `smart-padel-court-trifold-PRINT-bleed3mm.pdf` | نسخه‌ی چاپخانه با ۳ میلی‌متر بلید از هر طرف (۳۰۳×۲۱۶ میلی‌متر) |

- تای رول (Roll fold)، راست‌به‌چپ. عرض پنل‌ها ۱۰۰ / ۱۰۰ / ۹۷ میلی‌متر؛ پنل ۹۷ میلی‌متری لت داخلی است.
- صفحه‌ی ۱ (رو): جلد (چپ) · پشت جلد با شماره‌ی تماس، QR دمو و لوگوی آماریا (وسط) · لت داخلی: مشکل‌ها و راه‌حل (راست).
- صفحه‌ی ۲ (داخل، از راست خوانده می‌شود): ۰۱ برای مشتری‌ها · ۰۲ برای مدیر باشگاه · ۰۳ درآمد بیشتر.
- متن‌ها برداری (vector) با فونت‌های وزیرمتن، دانا و لاله‌زار جاسازی‌شده؛ تصاویر اپ با وضوح ۳ برابر (۱۱۷۰×۲۵۳۲).
- رنگ‌ها RGB هستند؛ اگر چاپخانه CMYK خواست، همین PDF را در نرم‌افزار چاپخانه تبدیل کنند.
- ساخت دوباره: `source/trifold.html` را ویرایش کنید و `node pdf.js` را اجرا کنید.
