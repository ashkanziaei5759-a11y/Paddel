# تیزر تبلیغاتی پرشین پدل

فایل نهایی: `persian-padel-teaser-1080p.mp4` — ‏1920×1080، ‏30fps، ‏H.264 + AAC، مدت **۵۵٫۵ ثانیه**.
بدون صدای گوینده؛ فقط موزیک زمینه‌ی اختصاصی و بدون حق کپی‌رایت (ساخته‌شده با هوش مصنوعی)،
با برش صحنه‌ها روی ضرب‌های اصلی آهنگ (۱۲۰ BPM).
همه‌ی متن‌ها با فونت **DanaFaNum** (Light / Regular / Bold) نوشته شده‌اند.
